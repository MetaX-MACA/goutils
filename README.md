# goutils

A small Go helper library.

## Packages

Import packages from `github.com/MetaX-MACA/goutils/<package>`.

| Package | Description |
| --- | --- |
| `appfs` | File and path helpers with an application-wide virtual root. |
| `graph` | Generic clique and connectivity helpers. |
| `must` | Panic-on-error helpers for tests, `init` and scripts. |

## Install

```bash
go get github.com/MetaX-MACA/goutils@latest
```

Requires Go 1.23.4 or later.
